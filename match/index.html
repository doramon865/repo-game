📌 วิธีทำให้ Sheet เป็น Public CSV URL
  1. เปิด Google Sheet → คลิก File → Share → Publish to web
  2. เลือก Sheet ที่ต้องการ → เลือกรูปแบบเป็น CSV
  3. คลิก Publish แล้วคัดลอก URL ที่ได้
  4. หรือนำ Sheet ID ไปใส่ใน URL รูปแบบ:
    https://docs.google.com/spreadsheets/d/ID/export?format=csv&sheet=Sheet1
